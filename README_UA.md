# Elation — Fantasy RPG Project

> **Навчальне завдання стало проєктом.**

Elation — це особистий проєкт у жанрі fantasy RPG, який розпочався як навчальне завдання зі створення Character Creator на JavaScript. Початкова робота дала мені основу, але ідея виявилася достатньо цікавою, щоб продовжити розвивати її самостійно.

Проєкт розвивається разом із моїми навичками розробниці — від невеликого Character Creator до фундаменту майбутнього більш масштабного fantasy RPG.

## Від навчального завдання до власного проєкту

Elation почався як навчальне завдання з JavaScript, але ідея Character Creator виявилася достатньо цікавою, щоб я продовжила розвивати її самостійно. Згодом проєкт став місцем, де я можу застосовувати нові знання, експериментувати, покращувати існуючу архітектуру, вивчати сучасні frontend-технології та поступово розширювати початкову ідею.

Elation більше не просто домашнє завдання. Це особистий проєкт, який розвивається разом зі мною.

---

## 🏗️ Поточний стан

Початковий Character Creator на Vanilla JavaScript поступово був мігрований на TypeScript та React. React зараз є основною UI-архітектурою проєкту, а [`src/main.tsx`](src/main.tsx) — application entry point.

Поточний проєкт використовує:

- Vite
- React
- TypeScript
- Bootstrap та CSS
- `localStorage`

Наразі фундамент проєкту зосереджений на Character Creator, даних персонажа, екіпіруванні, вихованцях, перегляді деталей і збереженні персонажів у браузері.

### Поточна функціональність

- процес створення персонажа;
- персонаж, зброя, обладунки та вихованець;
- список персонажів;
- Character Details modal;
- validation feedback;
- збереження персонажів через `localStorage`.

Це поточні можливості проєкту. Майбутні ідеї описані окремо нижче.

## 📚 Навчання та розвиток

Elation розвивається паралельно з моїм навчанням. Зараз я продовжую вивчати:

- TypeScript
- React
- React Query
- routing
- Next.js
- інші сучасні frontend-технології

Вивчення Next.js не означає, що Elation зараз переноситься з Vite на Next.js. Поточний стек проєкту залишається **Vite + React + TypeScript**. Next.js є частиною мого навчання та може стати майбутнім напрямом, якщо проєкту справді знадобиться така архітектура.

## 🧭 Принцип розвитку

Elation розвивається поступово. Я не хочу реалізовувати все одразу.

Мій підхід простий:

**навчитися технології → зрозуміти концепцію → застосувати її в проєкті → рухатися далі**

Проєкт росте разом із моїми навичками, а не намагається одразу стати готовою RPG.

Codex використовується як інструмент розробки, але моя мета — поступово самостійно розуміти архітектуру, код і технічні рішення проєкту.
